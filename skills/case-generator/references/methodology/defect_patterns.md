# 缺陷模式库（检出用）

> 与业务模块清单的分工：本文件按**症状**归类（跨模块通用），模块内的常见坏法见 `references/business-pitfalls.md`（登录/上传/支付/导入等）。
>
> 用途：① 盲测 `hidden_answers` 从这里取模式，避免"随手编一个不可能出现的缺陷"；
> ② 执行期按类别逐条排查，减少"只测了 happy path"。
> 每条给出最小触发、观察点与常见误判；误判细节见 `false_positive_guard.md`，判定链见 `detection_methods.md`。

---

## 1. 功能

| 模式 | 最小触发 | 观察点 | 常见误判 |
|---|---|---|---|
| 成功提示但未落库 | 提交后刷新/重进列表 | 提示成功、列表无新记录 | 异步延迟 → 需读回或轮询确认 |
| 同操作两种结果 | 连续两次相同操作 | 一次成功一次静默失败 | 服务端限流属预期 → 查契约 |
| 编辑被静默丢弃 | 修改后点返回/切 tab | 再次进入恢复旧值且无提示 | 有"未保存"提示则不算 |
| 删除后仍可访问 | 删除后直连详情 URL | 页面仍展示完整数据 | 软删除且有明确策略 → 按策略判 |
| 批量部分失败无汇总 | 混合可选/不可选记录批量操作 | 只提示"操作完成"，失败项不列 | 全部成功时无汇总属正常 |
| 入口消失无替代 | 无数据/无权限时的主操作 | 按钮直接不渲染且无说明 | 权限隐藏属合法 → 见误报 §4 |

## 2. 数据

| 模式 | 最小触发 | 观察点 | 常见误判 |
|---|---|---|---|
| 边界未拦截 | 上界+1 / 下界-1 / 空串 | 保存成功或截断无提示 | 需求允许截断 → 查规则 |
| 特殊字符破坏展示 | 输入 `<>&"'`、emoji、RTL | 页面错乱、导出乱码 | 转义后正常显示即不算 |
| 精度/单位丢失 | 金额 0.005、重量 1.005kg | 四舍五入方向错误、单位缺失 | 需求未定义精度 → 记待确认 |
| 分页/排序错位 | 排序后翻页、跨页勾选 | 第 2 页重复/遗漏；选择被清空 | 需求明确"仅当前页" → 不算 |
| 时间口径错误 | 跨时区/夏令时/月末 | 显示 UTC 当本地、月末加一月溢出 | 需求声明用 UTC → 不算 |
| 导入导出不一致 | 导出再导入 | 字段丢失、编码变化、行数变化 | 模板明确不支持字段 → 不算 |

## 3. 状态

| 模式 | 最小触发 | 观察点 | 常见误判 |
|---|---|---|---|
| 状态残留 | 审批驳回后返回列表 | 仍显示"待审批" | 缓存未刷新 → 强刷后仍残留才算 |
| 中间态卡死 | 异步任务中断/超时 | 一直"处理中"，无重试/取消 | 有超时兜底提示 → 降为建议 |
| 返回丢上下文 | 筛选+翻页后进详情再返回 | 筛选重置、回到第 1 页 | 产品明确重置 → 不算 |
| 双开冲突 | 两个标签页编辑同一条 | 后保存覆盖先保存且无提示 | 有版本冲突提示 → 不算 |
| 非法状态迁移 | 直接调接口把草稿置为已通过 | 接口接受非法迁移 | 内部接口且有鉴权 → 按安全类判 |

## 4. 权限与会话

| 模式 | 最小触发 | 观察点 | 常见误判 |
|---|---|---|---|
| 越权直达 | 低权账号直接访问高权 URL/接口 | 返回数据或执行成功 | 前端隐藏但接口拒绝 → 不算 |
| 越权按钮可点 | 低权账号看详情页 | 高权按钮可见可点且生效 | 可点但服务端拒绝并提示 → 记易用问题 |
| 会话失效处理 | 清 cookie/过期后操作 | 白屏、报错栈、无限跳登录 | 正常跳登录并回跳 → 不算 |
| 数据越界 | A 租户改 ID 访问 B 租户数据 | 返回他人数据 | 共享数据且有授权 → 不算 |
| 登出未清态 | 登出后后退 | 仍能看到上一个人的数据 | 浏览器缓存展示但接口拒绝 → 记安全风险 |

## 5. 界面

| 模式 | 最小触发 | 观察点 | 常见误判 |
|---|---|---|---|
| 重叠/截断 | 长标题、长用户名、超长数字 | 文本压住图标、列宽撑破 | 有省略号+tooltip → 不算 |
| 空态缺失 | 清空数据/首次进入 | 空白页无引导 | 需求未要求空态 → 建议 |
| 对齐/间距漂移 | 与同页同类组件对比 | 同层级卡片间距不一致 | 设计稿未覆盖 → 待确认 |
| 暗色/高对比失效 | 切主题/系统高对比 | 文字与背景对比不足 | 未承诺暗色 → 不判 |
| 加载态跳变 | 慢网/大列表 | 骨架屏→内容布局跳动 | 轻微位移属可接受 → 记建议 |
| 错误态无出口 | 接口 500 | 整页空白、无重试 | 有全局错误页 → 不算 |

## 6. 易用与无障碍

| 模式 | 最小触发 | 观察点 | 常见误判 |
|---|---|---|---|
| 键盘不可达 | 只用 Tab/Enter | 主操作按钮跳过、焦点不可见 | 有 skip-link 且可达 → 不算 |
| 危险操作无确认 | 点"彻底删除" | 直接执行 | 有撤销机制 → 降为建议 |
| 反馈缺失 | 点击无跳转的按钮 | 3 秒内无任何状态变化 | 有 loading 但无文案 → 建议 |
| 错误定位不清 | 多字段表单提交失败 | 只提示"输入有误"不指字段 | 有字段级红框 → 不算 |
| 重复提交 | 快速双击提交 | 产生两条记录/两次扣款 | 有防抖且只一次 → 不算 |
| 文案不可读 | 错误提示含错误码/英文栈 | 用户无法据此恢复 | 有"联系管理员"指引 → 降级 |

## 7. 文案

| 模式 | 最小触发 | 观察点 | 常见误判 |
|---|---|---|---|
| 变量未渲染 | 触发含变量的提示 | 显示 `{{name}}`、`%s`、`undefined` | 后台配置占位符属设计 → 查规则 |
| 术语不一致 | 同对象在列表/详情/提示 | "问卷/表单/项目"混用 | 不同层级确有区分 → 查术语表 |
| 单位/精度缺失 | 金额、时长、容量 | "3" 无单位、"1.5" 无精度 | 表头已声明单位 → 不算 |
| 时间口径混用 | 列表与详情对比 | 一处相对时间一处绝对时间且不一致 | 产品明确混排 → 建议 |
| 按钮语义空泛 | 主操作按钮 | "提交""确定"无对象 | 上下文明确 → 建议 |
| 错误文案不可行动 | 校验失败 | 只说"失败"不说下一步 | 有帮助链接 → 降级 |
| 国际化残留 | 切语言 | 中英混排、拼接语序错误 | 未承诺 i18n → 不判 |

## 8. 兼容

| 模式 | 最小触发 | 观察点 | 常见误判 |
|---|---|---|---|
| 第二内核布局坏 | Firefox/WebKit 实机或真实内核 | 表单错位、日期控件不可用 | 仅视口缩放 → 不能判内核问题 |
| 设备能力缺失 | 触屏/无 hover/小屏 | hover 才出现的操作在触屏不可达 | 明确不支持移动端 → 不判 |
| 字体/缩放 | 200% 缩放、系统大字体 | 文本截断、按钮溢出 | 浏览器最小字号导致 → 记建议 |
| 下载/剪贴板受限 | Safari/隐私模式 | 复制失败无提示 | 浏览器策略限制且有提示 → 不算 |

## 9. 性能（有指标才判）

| 模式 | 最小触发 | 观察点 | 常见误判 |
|---|---|---|---|
| 首屏超预算 | 冷启动 + 慢网 | 超过需求承诺时间 | 无指标 → 只记录 |
| 操作无响应 | 大列表批量操作 | 5 秒无反馈且无进度 | 有进度条 → 记录耗时 |
| 重复请求 | 连续切 tab/重试 | 同请求风暴、无取消 | 框架行为但无影响 → 建议 |

## 10. 接口（layer=api 的 TC，交 `skills/api-test`）

| 模式 | 最小触发 | 观察点 | 常见误判 |
|---|---|---|---|
| 契约不符 | 必填缺失/类型错/多余字段 | 返回 200 且静默忽略 | 契约声明可选 → 不算 |
| 错误码与语义不符 | 参数错误 | 返回 500 或 200+error | 网关统一包装 → 查契约 |
| 幂等缺失 | 同 key 重复提交 | 多条记录/重复扣款 | 契约声明非幂等 → 不算 |
| 越权 | 换 token/改 ID | 返回他人数据 | 公开资源 → 不算 |

---

## 使用纪律

1. 排查时**按类别过一遍**，不要只走主流程；每类至少问一句"这类在这页会怎么坏"。
2. 命中模式不等于缺陷：必须补齐 `detection_methods.md` 的判定链与证据。
3. 盲测答案键里的每条 `hidden_answers` 都应能指回本文件某个模式；指不回去的，说明是臆造缺陷，应删。
