## 1. 边界分析 + 等价类划分

### 1.1 适用条件

输入有明确的范围、长度、数量、格式限制时使用。

### 1.2 用例结构

| 用例类型 | 设计要点 | 示例（密码 8-20 位） |
|----------|----------|---------------------|
| 有效等价类 | 设置合规典型值 → 执行 → 验证通过 | 输入 12 位含大小写字母+数字 |
| 有效边界 | 设置最小值、最大值 → 执行 → 验证通过 | 输入 8 位、输入 20 位 |
| 无效边界 | 设置最小值-1、最大值+1 → 执行 → 验证拒绝 | 输入 7 位、输入 21 位 |
| 无效等价类 | 每个违规类型各一条 → 验证错误提示 | 全小写、无数字、纯特殊字符 |
| 特殊值 | 空值、null、0、空格、Unicode | 输入空、输入仅空格 |

- [ ] 最小值

## 2. 异常场景分类（六类）

异常测试不能笼统写"验证异常情况"，必须落到以下分类：

| 异常类别 | 说明 | 用例示例 |
|----------|------|----------|
| **输入异常** | 无效格式、超长/超短、空值、特殊字符 | 邮箱格式错误时注册 → 提示「邮箱格式不正确」 |
| **流程异常** | 流程中断、回退、重复提交、跳过必填步骤 | 下单中途关闭页面 → 订单状态不变 |
| **环境异常** | 网络中断、服务超时、磁盘满、并发冲突 | 支付接口超时 → 订单保留待支付状态 |
| **权限异常** | 未登录访问、越权操作、Token 过期、角色不足 | 普通用户访问管理后台 → 403 拒绝 |
| **数据异常** | 数据不存在、重复数据、关联数据被删除 | 查询已删除的商品 → 提示「商品不存在」 |
| **状态异常** | 非法状态转换、重复操作、时效性超期 | 已取消订单申请发货 → 提示「订单已取消」 |

**覆盖底线**：每个业务域至少覆盖 **输入 + 流程 + 权限** 三类异常，其余按实际场景补充。

## 3. 状态迁移边界

实体有明确状态流转时，除合法路径外必须补充：

- 非法逆向转换（如：已发货 → 待支付）
- 非法跳跃转换（如：已支付 → 已完成，跳过发货）
- 重复触发同一转换（幂等性）
- 状态回退与循环
- 超时导致的自动状态变更（如：待支付超时自动取消）

---

## 4. 权限边界

- 未登录访问受保护资源
- 低权限角色访问高权限功能
- 跨部门 / 跨租户数据可见性
- Token 过期后的操作
- 权限被回收后的残留会话

---

## 5. 数据一致性边界

- 前端展示值 vs 数据库实际值
- 关联数据被删除后的展示（外键失效）
- 并发修改同一条记录
- 分页边界（第一页、最后一页、超出总页数）
- 排序边界（空列表、单条数据、同值排序）
