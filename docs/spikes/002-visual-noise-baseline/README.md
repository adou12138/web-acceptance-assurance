# Spike 002 · 视觉噪声基线（visual-noise-baseline）

> 状态：**PARTIAL**——协议与噪声分类框架已定义；**截图对比未实跑**（本机无浏览器
> 运行时，且方案 §9 明确不自动安装 Playwright/Chrome）。不伪造结论，实跑留待
> 有浏览器通道的会话。spike 产物不作为产品验收证据，不更新正式视觉基线。

## 问题（Given/When/Then）

- **Given** 相同页面、浏览器、字体、视口、数据和动画状态。
- **When** 连续生成两次截图。
- **Then** 能区分稳定差异、字体/动态噪声和真实布局变化。

## 方法（协议，待实跑）

1. 固定环境：同一 Chrome 二进制、`--force-device-scale-factor=1`、禁用动画
   （`prefers-reduced-motion` 或注入 CSS `*{animation:none!important}`）、同一视口
   （1440×900 与 320×640 两档）、同一数据快照、字体用系统回退集并记录。
2. 连续截图两次（间隔 ≥1s），逐像素 diff，产出差异像素掩码。
3. 按掩码分布分类：

| 类别 | 特征 | 处置 |
|---|---|---|
| 动态噪声 | 时间戳/轮播/随机头像等位置固定的小簇，两次采样位置一致 | 记入噪声清单，不进差异结论 |
| 字体渲染噪声 | 文本边缘亚像素抖动，簇沿文本行分布 | 阈值容差（如 <2px 位移不判差异） |
| 真实布局变化 | 大面积错位/元素消失/层级变化 | 进入视觉差异结论，需人工核对 |
| 稳定差异 | 两次采样一致且面积 > 阈值 | 真实差异，报具体区域 |

4. 判定口径：**无基线时不输出像素级通过/品牌相似度结论**（`visual-usability.md`）；
   本 spike 只标定"噪声 vs 变化"的区分能力。

## 边界

- 无浏览器运行时，步骤 1-4 未实跑，阈值（位移容差、面积阈值）无实测标定；
- 字体子像素渲染在不同 GPU/驱动下噪声特征不同，标定结果不可跨机器外推；
- 掩码分类需要视觉走查辅助，纯像素 diff 无法区分"合法动效"与"布局回归"。

## 结论

**PARTIAL**：框架与口径已就绪；区分能力的实证（两次截图 diff 的噪声边界）待浏览器
环境实跑后回填本文件，实跑前不得引用本 spike 作为视觉对比能力的依据。
