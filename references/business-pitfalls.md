# 业务模块坑点库（Web 需求测试用）

> 用途：按**业务模块**参考"这类功能通常怎么坏"，补 `defect_patterns.md`（按症状分类）缺的"业务上下文"。
> **这是攻击假设生成的知识输入之一，不是必须逐项核对的检查表。** 清单未覆盖的风险面与清单内条目在攻击设计中具有同等地位；本文件的覆盖范围不构成对专家自主攻击设计的限制。清单已覆盖 ≠ 攻击面已覆盖。
> 分工：本文件回答"登录/上传/支付/导入这些模块 historically 容易坏在哪"；`defect_patterns.md` 回答"看到这个现象算不算缺陷"；
> 判定链与证据要求见 `methodology/detection_methods.md`，误报降级见 `methodology/false_positive_guard.md`。
>
> **来源与取舍**：模块清单与风险项改编自本机专家 `bug-test-expert`（全链路测试专家，业务坑点知识库）与 `qa-testing`（OWASP 覆盖目标）、
> `ai-product-testing-expert`（AI 功能评测），只保留 Web 新需求验收相关的部分；移动端/车载/IoT/MQ/混沌工程等不在本专家范围，未搬运。
> 安全相关只做**防护验证**（是否拦截/是否泄露），不构造攻击载荷、不做渗透。

---

## 1. 登录与会话

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 错误密码 / 账号不存在 | 提示是否区分"账号不存在"与"密码错误"（账号枚举） |
| 高 | 连续失败 | 锁定策略是否生效、锁定期是否可绕过（换 IP/换入口） |
| 高 | 会话过期 | 过期后操作是否被拒、是否回跳登录并保留原地址 |
| 中 | 多端登录 | 后登录是否踢掉前一个、被踢端是否有提示 |
| 中 | 验证码 | 是否可重复使用、有效期、频率限制、绕过（直接调接口） |
| 低 | 退出登录 | 后退是否能回到已登录页面；本地缓存是否清理 |

## 2. 权限与数据边界

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 低权角色直连 URL/接口 | 垂直越权：能否进入高权页面、能否执行高权操作 |
| 高 | 改 ID / 遍历 | 水平越权：能否读到/改到他人数据 |
| 中 | 角色切换 | 权限是否即时生效、菜单与按钮是否同步刷新 |
| 中 | 按钮 vs 接口 | 前端隐藏但接口是否拒绝（前端隐藏不算权限） |
| 低 | 无权限提示 | 是空白页/报错栈，还是有明确说明与申请入口 |

## 3. 表单与提交

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 重复点击/回车/刷新重提 | 是否产生两条记录（幂等） |
| 高 | 校验失败 | 已填内容是否保留、错误是否定位到字段 |
| 中 | 必填/格式/长度 | 前端校验能否被绕过（改请求） |
| 中 | 联动字段 | 改 A 后 B 的选项/校验是否同步更新 |
| 中 | 草稿/暂存 | 离开页面是否丢失、恢复后是否错位 |
| 低 | 成功反馈 | 是否只有 toast 无跳转、列表是否刷新 |

## 4. 文件上传 / 下载

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 改扩展名/改 MIME | 是否双重校验（扩展名 + 文件头），不只信前端 |
| 高 | 超大文件 / 超量 | 是否有上限、失败是否有明确提示、是否留下半成品 |
| 高 | 文件名特殊字符 | `../`、引号、超长名是否被处理，是否可覆盖他文件 |
| 中 | 同名文件 | 覆盖还是重命名，是否有版本 |
| 中 | 下载鉴权 | 直接拿链接能否下载他人文件 |
| 低 | 预览 | 图片/PDF/Office 预览是否错乱、是否有兜底 |

## 5. 支付 / 交易（涉及才查）

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 重复回调 | 是否只处理一次（幂等键/状态机） |
| 高 | 金额精度 | 分/元换算、四舍五入方向、优惠后金额 |
| 高 | 超时关单 | 未支付订单是否自动关闭、关闭后回调如何处理 |
| 中 | 退款 | 重复退款、超额退款、部分退款后状态 |
| 中 | 对账 | 订单状态与支付流水是否一致（读回核对） |
| 低 | 结果通知 | 支付成功但页面未刷新、通知丢失是否有补偿 |

## 6. 批量导入 / 导出

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 部分失败 | 是全部回滚还是部分入库；失败明细是否给行号与原因 |
| 高 | 大量数据 | 10 万行级是否超时/内存溢出/卡死主线程 |
| 中 | 模板校验 | 列头、必填、枚举、唯一性、引用完整性 |
| 中 | 编码 | UTF-8/GBK、BOM、特殊字符、前后空格 |
| 中 | 重复数据 | 去重策略是覆盖、跳过还是报错 |
| 低 | 导出 | 导出字段与列表一致、大数据量分片、文件名可读 |

## 7. 异步任务与外部回调

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 任务中断/超时 | 是否卡在"处理中"、有无重试/取消/超时兜底 |
| 高 | 回调乱序/重复 | 状态是否被旧回调覆盖、重复回调是否幂等 |
| 中 | 进度反馈 | 是否有进度与预计时间、失败是否可重试 |
| 中 | 多实例 | 是否重复执行（分布式锁） |
| 低 | 完成通知 | 站内信/邮件失败是否影响主流程 |

## 8. 接口与契约（页面侧观察，深测交 `skills/api-test`）

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 参数缺失/类型错 | 是否 200 静默成功、错误码是否与语义一致 |
| 高 | 越权 | 换 token/改 ID 是否返回他人数据 |
| 中 | 异常返回 | 是否抛堆栈、是否泄露内部字段 |
| 中 | 契约漂移 | 页面字段与接口文档/实际返回是否一致 |
| 低 | 响应脱敏 | 手机号/证件号/地址是否按规则脱敏 |

## 9. 兼容与设备

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 第二内核（真机/真实内核） | 核心流程是否可用（不是只看布局） |
| 中 | 视口/缩放/大字体 | 是否截断、重叠、按钮溢出 |
| 中 | 触屏/无 hover | hover 才出现的操作在触屏是否可达 |
| 低 | 下载/打印/剪贴板 | 浏览器策略限制下是否有提示与替代 |

## 10. 弱网与网络异常

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 5xx / 断网 | 是否仍显示成功、是否有重试且不重复提交 |
| 高 | 超时 | 是否有超时提示、是否可恢复、是否留下脏数据 |
| 中 | 慢网 | 加载态是否可见、是否可取消 |
| 中 | 断点恢复 | 重连后是否重复请求、状态是否错乱 |

## 11. 安全基线（仅防护验证）

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 输入回显 | 是否存在 XSS（输入 `<script>` 类字符是否被转义/拦截） |
| 高 | 越权/未授权 | 未登录、低权、他人资源三类访问是否被拒 |
| 中 | 错误信息 | 是否暴露堆栈、SQL、内部路径、版本号 |
| 中 | 敏感数据 | 响应/页面/日志是否明文手机号、证件、密码 |
| 中 | CSRF/重放 | 关键写操作是否有防重放（token/一次性签名） |
| 低 | 安全配置 | 默认账号、目录列表、调试开关是否关闭 |

> 纪律：只验证"是否拦截/是否泄露"，不构造真实攻击、不扫描第三方、不使用未授权账号。
> 每一项的验法、证据形态与"不算缺陷"情形见 `references/security-verification.md`（12 项外部可验防护 + OWASP 映射 + 结论边界）。

## 12. 可访问性（基础面，非合规认证）

> 条级清单、影响分级、键盘 12 步与读屏（VoiceOver/NVDA）实测口径见 `references/a11y-audit.md`；本表只列"先看什么"。

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 键盘操作 | 主流程是否可纯键盘完成、焦点是否可见 |
| 中 | 焦点顺序 | Tab 顺序是否跟随视觉顺序、是否跳过主操作 |
| 中 | 表单标签 | 输入框是否有可读标签、错误是否与字段关联 |
| 中 | 图片替代 | 信息图是否有 alt、装饰图无 alt 属合法 |
| 低 | 对比度 | 正文/按钮文字对比是否明显不足（不宣称 WCAG 等级） |

## 13. 国际化 / 本地化

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 中 | 长文案 | 英文/德文变长后是否截断/溢出 |
| 中 | 变量拼接 | 语序是否被硬编码、变量是否错位 |
| 中 | 数字/日期/货币 | 千分位、小数点、日期格式、货币符号是否随语言 |
| 低 | 时区 | 跨时区显示与"今天"的判定 |
| 低 | 翻译缺失 | 是否回退到 key 或空白 |

## 14. 时间与时区

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 中 | 跨时区 | 显示本地时间还是服务器时间、是否标注时区 |
| 中 | 月末/闰年/夏令时 | 加一月、加一年是否溢出；夏令时切换是否错一小时 |
| 中 | 有效期 | 到期边界（含/不含）、到期后行为 |
| 低 | 相对时间 | "3 分钟前"在跨天后是否错误 |

## 15. AI 生成 / 对话功能（涉及才查）

> 判定标准、可复现参数、八个场景与上线门禁见 `skills/case-generator/references/methodology/ai_feature_testing.md`；下表只列排查入口。


| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 业务规则被改写 | 回答是否与规则原文冲突（规则性幻觉优先于知识性幻觉） |
| 高 | 注入 | 用户输入伪装指令能否让模型越权/泄露系统提示 |
| 高 | 特殊字符串消息静默丢失 | 含路径串/特殊载荷的消息无回复、无气泡、无报错——网络钩子与 DOM 两层核实后再判，列入每轮回归 |
| 高 | 写入结论同源互证 | Agent 自写自读不构成独立验证——写入类结论需新会话冷读+产物页直读交叉核对 |
| 中 | 多轮一致性 | 同一规则在多轮追问下是否自相矛盾 |
| 中 | 不可复现 | 是否固定参数（temperature/top-p）、是否有重复次数与记录 |
| 中 | 专属能力误判不适用 | 仅特定类型/套餐可用的能力在错误载体上被拒就判"不适用"——须换专属载体重测 |
| 低 | 无依据断言 | 是否给出来源/置信提示，还是"看起来像"就下结论 |

## 16. 界面样式与布局（每次页面检查都适用）

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 元素遮挡/重叠 | 弹层压住主操作、粘性页脚盖住最后一行、浮层与内容互相覆盖 |
| 高 | 文本溢出/截断致信息缺失 | 超长名称、长数值、长单位、多语言文本在容器内被截且无查看全文入口 |
| 高 | 容器撑破/横向滚动 | 长串英文/URL/表格/代码块把页面撑出横向滚动条 |
| 中 | 错位与对齐 | 同组按钮基线不齐、标签与输入框错行、表格列错位 |
| 中 | 空态/满态两端 | 0 条数据、1 条数据、1000 条数据三种极端的布局与可读性 |
| 中 | 图片失效/变形 | 破图、比例失真、渐变或图片上的文字实际可读性（须按截图看，不能按纯色算） |
| 中 | 布局抖动 | 字体/图片加载完成后元素位移、骨架屏到真实内容的跳变 |
| 低 | 主题/缩放 | 200% 缩放与浏览器最小字号下是否仍可用 |

## 17. 文案与术语（content 必选属性）

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 未渲染变量残留 | `{{name}}`、`%s`、`null`、`undefined`、`NaN` 直接出现在界面或提示里 |
| 高 | 提示误导 | 成功提示与业务结果不一致（提示已保存但列表没变）、危险操作提示过于轻描淡写 |
| 高 | 错误未定位到字段 | 报错只说"提交失败"，不说是哪个字段、为什么、怎么改 |
| 中 | 术语不一致 | 同一对象在按钮/标题/提示/导出里叫法不同；单位与精度不一致 |
| 中 | 按钮语义与结果不符 | "保存"实际是"另存为新版本"、"删除"实际是软删不可恢复 |
| 中 | 错别字/语病/标点混用 | 中英文标点混用、重复字、机器翻译式表达 |
| 中 | 空态/失败态无文案 | 空白页只有图标没有说明，用户不知道下一步 |
| 低 | 大小写与数字格式 | 日期/金额/百分比格式在同页不一致 |

## 18. 操作逻辑与交互（usability 必选属性）

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 缺防重 | 双击、回车连按、网络慢时重复点击 → 重复创建/重复扣减 |
| 高 | 缺加载态 | 提交后无任何反馈，用户不知道是否生效，只能反复点 |
| 高 | 危险操作无反悔 | 删除/覆盖/发布无二次确认，且无撤销或找回入口 |
| 高 | 必填与校验不一致 | 标了必填但可以提交；没标必填却报必填错误 |
| 中 | 绕路与重复输入 | 同一信息在多个步骤反复填写；高频任务被藏在三级菜单 |
| 中 | 状态与按钮不一致 | 已发布的对象仍显示"发布"按钮；无权限的按钮可见但点击报错 |
| 中 | 中断恢复 | 刷新/返回/关闭再打开后，未保存内容是否保留、半完成状态是否残留 |
| 中 | 焦点与滚动 | 打开弹层后焦点未进入、关闭后未回到触发元素、页面被滚到顶部 |

## 19. 数据一致性（三通道对账）

| 风险 | 触发 | 先看什么 |
|---|---|---|
| 高 | 前端展示≠后端数据 | 列表显示已保存，详情/刷新/重新登录后是旧值或空值 |
| 高 | 缓存未失效 | 修改后本端显示新值、另一端/新标签页仍是旧值且无提示 |
| 高 | 跨视图不一致 | 列表、详情、导出、统计四处对同一对象的数量/状态/金额不一致 |
| 中 | 跨会话不一致 | A 会话修改，B 会话已打开页面不做任何提示就覆盖写入 |
| 中 | 异步最终一致无兜底 | 异步任务失败后无重试/无错误提示，界面停在"处理中" |
| 中 | 删除后残留 | 删除后列表消失但详情仍可访问、导出仍包含、搜索仍命中 |
| 低 | 时间与时区 | 同一条记录在不同时区展示出不同"日期"且无时区标注 |

## 使用纪律

1. **按模块勾选**：需求涉及哪些模块，就过哪些表；勾中的项转成具体用例或探索条目，不勾的写明"本次不涉及"。
2. **命中不等于缺陷**：模块表只提示"往哪看"，是否成立仍走判定链与证据要求。
3. **不虚构阈值**：需求没给性能/兼容指标时，只记录实测值与环境，不写"超过 2 秒即缺陷"。
4. **盲测对应**：`detection-fixtures` 的场景应能指回本文件的模块与 `defect_patterns.md` 的模式；指不回去的答案视为臆造。
