# 无障碍人工审计（键盘 · 读屏 · 缩放）

> 与 7.41 内置 15 条规则的分工：内置规则**单次运行即出结论**，但只覆盖"能纯计算"的那部分；
> 本文件补它明确声明**未覆盖**的部分——键盘可达与焦点顺序、动态内容播报、屏幕阅读器实测、
> 200% 缩放重排、动效可关闭、字幕与音频描述。两者结论必须分开陈述，不得合并成"通过 WCAG"。

## 一、单条判定的四要素

一条无障碍缺陷要成立，必须同时给出：

1. **用户群与障碍**：哪类用户（键盘、读屏、低视力、色觉、认知、前庭敏感）因此做不到什么；
2. **可复核判据**：对应条款号 + 本次实测到的具体状态（哪个元素、什么操作、什么结果）；
3. **证据**：DOM 片段/截图/读屏朗读文本/焦点序列记录，四者至少一项；
4. **影响**：阻断（核心流程无法完成）、严重（需绕行）、一般（体验受损）。

只有"看起来不对"没有第 2、3 项时，记**待确认**，不记缺陷。这是 `false_positive_guard.md` 在无障碍域的落地。

## 二、影响分级（用于定级，不用于判定）

| 级别 | 典型情形 | 处置 |
|---|---|---|
| 阻断 | 功能图缺替代文本、交互元素键盘完全不可达、表单控件无标签、自动播放媒体无控制 | 按 blocker 报 |
| 严重 | 对比度不足、缺跳转链接、自定义控件不可操作、页面无标题 | 按 major 报 |
| 一般 | 缺语言属性、链接文案不明确、缺地标、标题层级跳跃 | 按 normal 报，允许与设计确认后降级 |

标题层级跳跃、地标缺失这类"可能出于视觉需要"的项，**默认记待确认**，不要直接判缺陷。

## 三、A/AA 清单（37 条）

口径：WCAG 2.1/2.2 A/AA 常用集；4.1.1（解析）已废止不计；WCAG 2.2 新增的 2.4.12、2.5.8、3.3.7、3.3.8 未纳入，涉及触摸/拖拽/重复输入/无认知测试的场景须另补。

方式列：`内置` = 7.41 已机械覆盖；`人工` = 必须实测；`双` = 内置先跑、人工复核边界。

## 四、键盘实测（12 步，逐页执行并记录焦点序列）

1. 只按 `Tab` 从地址栏进入页面，记录**前 5 个焦点**是否合理（首个焦点不应是隐藏元素）。
2. 全程走完一次核心流程：进入 → 填写 → 提交 → 结果页。中途**不得使用鼠标**。
3. 每个可交互元素获焦时：焦点指示是否可见（截图对比获焦/未获焦）。
4. 自定义下拉、日期选择、树、标签页：`Enter`/`Space` 能否打开，方向键能否移动选项，`Esc` 能否关闭。
5. 弹窗/抽屉：打开后焦点是否进入弹窗、是否被限制在弹窗内、关闭后是否回到触发元素。
6. 表格与列表：能否进入、逐行移动、执行行内操作。
7. 上传控件：能否纯键盘完成选择文件。
8. 富文本/编辑器：工具栏按钮是否可达（若不可达，是否提供等价入口）。
9. 连续 `Tab` 至少 3 轮，确认**无循环陷阱**、无"焦点消失"（落到 body）。
10. `Shift+Tab` 反向走一遍，确认顺序可逆。
11. 破坏性操作（删除/提交）：焦点默认位置是否在最安全选项，而非"确认"。
12. 记录完整焦点序列（`元素 → 名称 → 可访问名称`），作为证据附件。

## 五、读屏实测

### 5.1 VoiceOver（macOS）

| 目的 | 操作 |
|---|---|
| 启停 | `Cmd+F5` |
| 朗读下一项 / 上一项 | `VO+→` / `VO+←`（`VO` = `Ctrl+Option`） |
| 交互（进入组件） | `VO+Shift+↓` |
| 退出交互 | `VO+Shift+↑` |
| 转子 | `VO+U` |
| 读全部 | `VO+A` |
| 点击获焦元素 | `VO+空格` |

### 5.2 NVDA（Windows）

| 目的 | 操作 |
|---|---|
| 启停 | `Ctrl+Alt+N` |
| 浏览模式 / 焦点模式切换 | `Insert+空格` |
| 下一项 / 上一项 | `↓` / `↑`（浏览模式） |
| 元素列表 | `Insert+F7` |
| 标题列表 | `Insert+F7` → 标题 |
| 朗读当前行 | `Insert+↑` |
| 停止朗读 | `Ctrl` |

### 5.3 每类组件的检查点

| 组件 | 必须听到什么 |
|---|---|
| 页面加载 | 页面标题、地标（"主导航""主内容"）、标题层级 |
| 链接/按钮 | 名称 + 角色（"链接""按钮"）；纯图标链接有名称 |
| 表单 | 标签、必填状态、格式要求；错误时听到**字段名 + 原因** |
| 自定义下拉/组合框 | 名称、角色、当前值、展开/收起状态、选项数量 |
| 标签页/手风琴 | 名称、选中/展开状态、位置（"2/5"） |
| 表格 | 行列表头关联；排序状态 |
| 弹窗 | 出现被播报、焦点进入、标题被朗读、关闭后回到原处 |
| 动态内容 | 提交结果、加载完成、校验失败**主动播报**（不等用户找） |
| 图片 | 信息图读出含义；装饰图**不朗读** |

判定口径：**"读屏能读到"不等于"读得懂"**。名称是"按钮 按钮"、图标读成"图片"、错误只播"出错了"，都按缺陷或待确认记。

## 六、缩放与重排

- 200% 浏览器缩放：核心流程可完成，内容不重叠、不裁切；
- 320px 视口（约 400%）：除表格/地图/图表等例外，不出现双向滚动；
- 文本间距按 1.4.12 注入（行高 1.5、段距 2 倍、字距 0.12em、词距 0.16em）后：无截断、无遮挡；
- 系统级"减少动态效果"开启后：非必要动画停止，功能不受影响；
- 高对比模式/强制颜色模式：控件边界与状态仍可辨。

## 七、结论怎么写

| 情形 | 写法 |
|---|---|
| 内置规则 + 人工实测均覆盖 | "无障碍：已实测 A/AA 共 N 条，其中 M 条不通过（列条款号与元素）" |
| 只跑了内置规则 | "无障碍：内置 15 条子集已跑，键盘与读屏**未实测**，不得视为合规" |
| 无法实测（无读屏环境/无真机） | "未实测：缺 <环境>，按 `evidence_grading.md` 记 E3，不写通过" |
| 需求不涉及界面 | "不适用：本次无界面变更"，须写理由 |

**禁止表述**："通过 WCAG 2.1 AA""无障碍合规""已满足无障碍要求"。可以写"已验X条，未验Y条，不通过Z条"。

## 八、常见误报

| 现象 | 为什么不算缺陷 |
|---|---|
| 装饰性插图无 `alt` | `alt=""` 是正确写法，读屏应跳过 |
| 隐藏区域（`display:none`/`aria-hidden`）对比度不足 | 不可见即不适用 |
| `disabled` 控件对比度低 | 1.4.3 豁免禁用态 |
| 原生 `<button>` 未写 `role` | 原生语义已正确，加了 role 反而可能出错 |
| 对比度按截图取色算错 | 半透明叠加、渐变、图片背景必须按实际渲染像素算，或标注"待确认" |
| 标题层级跳跃 | 可能是视觉设计需要，需与设计确认后再定级 |
| 视频无字幕但无语音内容 | 无音频即无需字幕 |
